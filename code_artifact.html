Как выложить эту игру на свой сайт (Бесплатно)

Всё уже готово в одном файле! Вся игра (графика, звуковой движок, прокачка и таблица лидеров) полностью упакована в этот единственный файл index.html. Чтобы игра появилась в интернете по вашей ссылке, выберите любой из 3 бесплатных способов ниже:

1 Самый простой способ за 30 секунд (Netlify Drop / Tiiny.host)

  1. Скопируйте код этой игры и сохраните его на компьютере под именем index.html в отдельную папку.
  2. Зайдите на сайт app.netlify.com/drop (или vercel.com).
  3. Просто перетащите папку с вашим файлом index.html прямо в окно браузера.
  4. Через 5 секунд вы получите готовую публичную ссылку вида ваш-кликер.netlify.app, которую можно скинуть друзьям!

2 Надёжный хостинг через GitHub Pages (Навсегда и бесплатно)

  1. Зарегистрируйтесь на github.com и нажмите New Repository.
  2. Назовите репозиторий (например, cyber-clicker), сделайте его Public.
  3. Нажмите Add file → Upload files, загрузите файл index.html и нажмите Commit changes.
  4. Перейдите во вкладку Settings → Pages и в разделе Branch выберите main и нажмите Save.
  5. Через 1 минуту игра будет доступна по адресу https://ваш-логин.github.io/cyber-clicker/.

3 Что нужно для работы онлайн-рейтинга на своем домене?

Прямо сейчас в этом окне облачный рейтинг уже подключён и работает! Если вы переносите файл на свой внешний хостинг и хотите общую базу игроков между разными устройствами:

  • Создайте бесплатный проект на console.firebase.google.com.
  • Включите Authentication → Anonymous и создайте базу Cloud Firestore.
  • Вставьте ваш объект firebaseConfig в блок скрипта внизу файла index.html.
  • Даже без настройки внешнего сервера игра автоматически сохраняет весь прогресс игрока и локальную таблицу рекордов прямо в браузере!
